# Reshak Telegram Bot

Telegram-бот ищет задания в двух учебниках Reshak.ru:

- Алгебра 9 класс, Макарычев
- Русский язык 9 класс, Бархударов
- Английский 9 класс, Spotlight
- Физика 9 класс, Перышкин
- Биология 9 класс, Пасечник
- Химия 9 класс, Остроумов
- История Нового времени 9 класс, Мединский и Чубарьян
- История России 9 класс, Мединский и Торкунов

Бот показывает предметы и учебники кнопками, после чего дает выбрать номер задания кнопкой. Номера разбиты на страницы, чтобы клавиатура Telegram не была слишком большой. Также номер можно ввести вручную. Бот запрашивает страницу задания при обращении, извлекает текст задания и изображения вариантов решения, а затем отправляет их в Telegram. Результаты кэшируются в SQLite на 6 часов.

## Запуск в Windows PowerShell

1. Установите Python 3.11 или новее.
2. Создайте бота у `@BotFather` командой `/newbot` и получите токен.
3. В этой папке выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
Copy-Item .env.example .env
```

4. Откройте `.env`, замените значение `BOT_TOKEN` на токен от BotFather.
5. Запустите:

```powershell
py -m app.bot
```

После запуска найдите своего бота в Telegram и отправьте `/start`.

## Запуск через BAT-файлы

Можно выполнить настройку двойным щелчком по `setup.bat`. Скрипт создаст `.venv`, установит зависимости и создаст `.env` из `.env.example`.

После добавления токена в `.env` запустите `start.bat`. Окно нужно оставить открытым, пока бот работает.

## Команды

- `/start` и `/help` запускают поиск.

Не коммитьте `.env`: в нем находится секретный токен.
